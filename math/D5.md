# D5 — repetition-code decoding

[P] There are two honest target transcripts, 0ⁿ and 1ⁿ. Group identities and
semantic calibration are fixed; an adversary can change at most b coordinates.
The target is the factual bit. Aliases sharing one fault controller are one
group; probability independence is not a premise of this bounded-fault result.

[B: lab] **Grade: kernel-checked.** `Alignment.Decoding.repetition_iff` proves
for all n,b∈ℕ that the two corruption balls contain no common length-n binary
transcript iff n≥2b+1. It uses actual `List Bool` transcripts. The zero ball has
at most b ones; the one ball has at most b zeros. These counts sum to n.
If n≥2b+1 they cannot both be ≤b. Otherwise the transcript with
min(b,n) ones followed by n−min(b,n) zeros is in both balls. This includes n=0
and oversized budgets. Axioms: `propext`, `Quot.sound`.

[B: lab] **Grade: kernel-checked.** `Alignment.Decoding.decoder_exists_iff`
now proves actual decoder existence iff n≥2b+1. `DecoderExists` quantifies a
function from binary reports to the true factual bit, correct on every length-n
report with at most b opposite coordinates. The constructed `majority` function
returns true exactly when ones outnumber zeros. `majority_correct` proves its
within-budget correctness; `decoder_implies_disjoint` rules out any decoder
on a collision. This closes the former written bridge and includes n=0 and
oversized fault budgets. Actual transitive axioms are in `lean/trust_base.txt`.
