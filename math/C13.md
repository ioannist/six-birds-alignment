# C13 — target-preserving carrier

[P] Fix the ordinary future language before quotienting. On S={0,1}² write a
state(d,c), where d names the beneficiary owed the next elective unit and c is
a service bit. Admitted ordinary operations retain d and either preserve,
toggle or reset c. The declared predictive readouts report only c and later
service bits, omitting duty identity. The protected target is T(d,c)=d.

[B: lab] **Grade: proved (written).** q(d,c)=c is sufficient for every admitted
ordinary future word: every operation's c update depends only on c, so induction
on words yields equal future readouts for equal q. Yet(0,0) and(1,0) have equal
predictive/current readouts and different owed beneficiaries. T does not descend
through q. This is not a contradiction of predictive sufficiency: its future
language explicitly omits the protected target. If the future language already
includes T, predictive sufficiency would have to retain it.

[B: lab] **Grade: kernel-checked.** `Alignment.Carrier.duty_split` checks that
split on Bool². `descent_iff_fibers` proves, for a surjective q, that a target
factors through q iff it is constant on q fibers. `repaired_target` and
`repair_preserves_current` show q⁺=(q,T) retains both readouts;
`repair_is_coarsest` shows every other carrier retaining q and T factors to q⁺.
Thus the repair is the least refinement relative to these fixed targets, up to
fiber equivalence. Standard axioms only, printed in `lean/trust_base.txt`.

[B: lab] **Grade: computed exact.** `python3 covenant_lab/carriers.py` checks
quotient consistency for every state pair and primitive operation, the split,
and the repair coordinates. Primitive consistency implies arbitrary-word
consistency by the written induction above; this is not a bounded-future mesh.

[B] This settles F2's logical issue on a declared carrier: a predictive quotient
can be a component, but needs target descent. It does not decide that every real
alignment relation has predictive surplus or that adding a duty coordinate
funds/enforces it. C3 shows how enforceability can add a further distinction.
